# Content Editor Guide

This guide is for content editors who create and manage page content in Jahia using the Bootstrap 5 component library.

## Available components

| Component | Description |
|-----------|-------------|
| [Accordion](components/accordion.md) | Collapsible content panels |
| [Alert](components/alert.md) | Contextual notification banners |
| [Breadcrumb](components/breadcrumb.md) | Automatic page hierarchy navigation |
| [Button](components/button.md) | Links and interactive triggers (modal, collapse, popover, offcanvas), with an optional tooltip |
| [Button group](components/button-group.md) | Several buttons placed together, side by side or stacked |
| [Card](components/card.md) | Flexible content containers with image, header, body, footer |
| [Carousel](components/carousel.md) | Image slideshow |
| [Figure](components/figure.md) | Image with optional caption |
| [Grid](components/grid.md) | Page layout: sections, containers, rows, columns |
| [Navbar](components/navbar.md) | Site navigation header, with sign-in, language and colour mode menus |
| [Pagination](components/pagination.md) | Page-by-page content navigation |
| [Progress bar](components/progress.md) | Shows how far something has gone |
| [Tabs](components/tabs.md) | Tabbed content panels |
| [Text](components/text.md) | Rich-text content block |
| Privacy Settings Modal | GDPR consent modal for Jahia Experience Manager (WEM). Available when WEM is active. Node type: `wemnt:privacySettingsModal`, view: `bootstrap5`. |

## Site-wide display

| Page | Description |
|------|-------------|
| [Colour mode](color-mode.md) | Light, dark or automatic display, the site default and the visitor's switcher |
| [Right-to-left languages](right-to-left.md) | Pages in Arabic, Hebrew and other right-to-left languages are mirrored automatically |

## Help texts

Many fields carry a short help text under their label in the content editor. It explains what the field does and what its choices mean. The help texts are available in six languages: English, French, German, Spanish, Italian and Portuguese.

## How to add a component

1. In edit mode, click the **+** button inside a droppable area
2. Browse or search the component picker
3. Select a Bootstrap 5 component
4. Fill in its properties in the Content Editor panel on the right
5. Publish when ready

## Color vocabulary

Many components share the same color palette derived from Bootstrap 5 contextual colors:

| Value | Meaning |
|-------|---------|
| `primary` | Brand color |
| `secondary` | Muted accent |
| `success` | Positive / green |
| `info` | Informational / blue |
| `warning` | Caution / yellow |
| `danger` | Error / red |
| `light` | Near-white |
| `dark` | Near-black |
